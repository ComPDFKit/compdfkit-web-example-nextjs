# ComPDF SDK for Web (Next.js Example)

As part of the KDAN ecosystem, [ComPDF SDK for Web](https://www.compdf.com/web?utm_source=github&utm_medium=compdfkit-web-example-nextjs&utm_campaign=compdfkit_web_example_nextjs_repo&ref_platform_id=github_compdfkit) is a powerful JavaScript-based PDF Library with a slick out-of-the-box responsive UI, which is ideal for developers looking to enhance web apps with powerful PDF features. It enables you to develop a Webviewer in multiple frameworks, including [Vanilla JavaScript](https://www.compdf.com/guides/pdf-sdk/web/make-a-program#integrate-into-a-vanilla-javascript-project?utm_source=github&utm_medium=compdfkit-web-example-nextjs&utm_campaign=compdfkit_web_example_nextjs_repo&ref_platform_id=github_compdfkit), [Vue.js](https://www.compdf.com/guides/pdf-sdk/web/frameworks/vue?utm_source=github&utm_medium=compdfkit-web-example-nextjs&utm_campaign=compdfkit_web_example_nextjs_repo&ref_platform_id=github_compdfkit), [React](https://www.compdf.com/guides/pdf-sdk/web/frameworks/react?utm_source=github&utm_medium=compdfkit-web-example-nextjs&utm_campaign=compdfkit_web_example_nextjs_repo&ref_platform_id=github_compdfkit), [Angular](https://www.compdf.com/guides/pdf-sdk/web/frameworks/angular?utm_source=github&utm_medium=compdfkit-web-example-nextjs&utm_campaign=compdfkit_web_example_nextjs_repo&ref_platform_id=github_compdfkit), [Next.js,](https://www.compdf.com/guides/pdf-sdk/web/frameworks/nextjs?utm_source=github&utm_medium=compdfkit-web-example-nextjs&utm_campaign=compdfkit_web_example_nextjs_repo&ref_platform_id=github_compdfkit) [Nuxt.js](https://www.compdf.com/guides/pdf-sdk/web/frameworks/nuxtjs?utm_source=github&utm_medium=compdfkit-web-example-nextjs&utm_campaign=compdfkit_web_example_nextjs_repo&ref_platform_id=github_compdfkit), [Svelte](https://www.compdf.com/guides/pdf-sdk/web/frameworks/svelte?utm_source=github&utm_medium=compdfkit-web-example-nextjs&utm_campaign=compdfkit_web_example_nextjs_repo&ref_platform_id=github_compdfkit), etc.

## Getting Started

1. Clone the repository:

    git clone https://github.com/ComPDFKit/compdfkit-web-example-nextjs.git
    cd compdfkit-web-example-nextjs

2. Install the dependencies of the example project with npm:

    npm install

For more information and operations, please visit our [development documentation](https://www.compdf.com/guides/pdf-sdk/web/nextjs?utm_source=github&utm_medium=compdfkit-web-example-nextjs&utm_campaign=compdfkit_web_example_nextjs_repo&ref_platform_id=github_compdfkit).
